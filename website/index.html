Quick Start Examples

Drop these snippets directly into your project to fetch a quote.

BASH curl command
curl -X GET "https://gita-quotes-api.onrender.com/api/v1/quotes/random"
JS fetch.js
const url = 'https://gita-quotes-api.onrender.com/api/v1/quotes/random';

fetch(url)
  .then(res => res.json())
  .then(data => console.log(data.data.quote));
PY request.py
import requests

url = "https://gita-quotes-api.onrender.com/api/v1/quotes/random"
data = requests.get(url).json()

print(data["data"]["quote"])

Frequently Asked Questions

Everything you need to know about using the API.

Is this API completely free?

Yes. This project is open-source and free to use for personal, educational, and commercial projects. No API keys or credit cards required.

Are there any rate limits?

To ensure the server remains stable for everyone, the API is currently limited to 60 requests per minute per IP address. If you exceed this, you will receive a 429 status code.

Where do the translations come from?

The English translations are carefully curated from widely accepted and respected public domain translations of the Bhagavad Gita, ensuring philosophical accuracy.
