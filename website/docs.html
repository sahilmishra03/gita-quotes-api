API Documentation

Welcome to the gitaquotes API documentation. Our RESTful API provides developers with immediate access to a curated collection of English translations from the Bhagavad Gita.

The API is designed to be extremely simple to integrate, returning fast JSON responses without the hassle of API keys or complex setups.

Base URL

BASE https://geeta-quotes-api-d35f6cf2ee12.herokuapp.com

Authentication

The gitaquotes API is entirely open and free. There is no authentication required. You do not need to register an account, pass an API key in your headers, or manage tokens. Just make standard HTTP GET requests to the endpoints.

Rate Limits

To ensure fair usage and maintain server stability for everyone, the API enforces a standard rate limit based on IP addresses.

  • Limit: 60 requests per minute per IP address.
  • Penalty: If you exceed this limit, the API will return a 429 Too Many Requests HTTP status code.

Status Codes

The API uses standard HTTP status codes to indicate the success or failure of an API request.

Code Description
200 OK The request was successful, and the response body contains the requested data.
404 Not Found The requested endpoint does not exist.
429 Too Many Requests You have exceeded the rate limit (60 requests per minute).
500 Internal Server Error Something went wrong on our end. Try again later.

Root Endpoint

A simple health-check endpoint that verifies the API is online and returns the primary endpoint path. Useful for pinging the service to ensure it is awake.

GET /

Response Format

Returns a simple JSON object confirming the API status.

JSON Response 
{
  "message": "gitaquotes API",
  "endpoint": "/api/v1/quotes/random"
}

Random Quote Endpoint

Fetches a single, randomly selected verse from the Bhagavad Gita. This is the primary endpoint for integration into widgets, daily quote apps, or bots.

GET /api/v1/quotes/random

Query Parameters

Parameter Type Description
lang (optional) String The language of the quote. Supported values: en (English), hi (Hindi), sa (Sanskrit).

Response Format

If no lang parameter is provided, the API returns a simple JSON object for backward compatibility:

JSON Response (Default) 
{
  "quote": "You have the right to work, but never to the fruit of work."
}

If the lang parameter is used (e.g., ?lang=hi), the API returns a structured response:

JSON Response (Multi-Language) 
{
  "success": true,
  "language": "Hindi",
  "quote": "तुम्हारा अधिकार केवल कर्म करने में है..."
}

Integration Examples

JavaScript (Fetch) 
fetch('https://geeta-quotes-api-d35f6cf2ee12.herokuapp.com/api/v1/quotes/random')
  .then(response => response.json())
  .then(data => console.log(data.quote))
  .catch(error => console.error('Error:', error));
Python (Requests) 
import requests

url = "https://geeta-quotes-api-d35f6cf2ee12.herokuapp.com/api/v1/quotes/random"
response = requests.get(url)
data = response.json()

print(data["quote"])
cURL 
curl -X GET "https://geeta-quotes-api-d35f6cf2ee12.herokuapp.com/api/v1/quotes/random"

Serial Quote Endpoint

Fetches a specific verse from the Bhagavad Gita using its serial number (1 to 101). This is perfect when you need to load a specific quote in a selected language.

GET /api/v1/quotes/{id}

Path Parameters

Parameter Type Description
id Integer The serial number of the quote (between 1 and 101).

Query Parameters

Parameter Type Description
lang (optional) String The language of the quote. Supported values: en (English), hi (Hindi), sa (Sanskrit). Defaults to en.

Response Format

The API returns a structured response containing the selected quote:

JSON Response 
{
  "success": true,
  "language": "English",
  "serial": 5,
  "quote": "I am death, which overcomes all, and the source of all beings still to be born."
}

Languages Endpoint

Fetches a list of all currently supported languages and their corresponding language codes.

GET /api/v1/languages

Response Format

Returns a simple JSON object containing arrays of supported languages and codes:

JSON Response 
{
  "success": true,
  "languages": ["English", "Hindi", "Sanskrit"],
  "supported_codes": ["en", "hi", "sa"]
}
